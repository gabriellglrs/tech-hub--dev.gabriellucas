# 📱 Soft Skills (Habilidades Blandas)

> Técnico sem soft skill é como ter um carro sem volante. Comunicação, liderança e trabalho em equipe são essenciais.

---

## 📚 O que são Soft Skills?

**Soft Skills** são habilidades interpessoais: comunicação, liderança, trabalho em equipe, resolução de problemas, gestão de tempo e apresentação. Diferente de hard skills, são transferíveis entre áreas.

### Por que é importante?

- **Comunicação** — explicar técnicos para não-técnicos
- **Liderança** — guiar equipes e projetos
- **Trabalho em equipe** — colaborar com devs, ops, segurança
- **Resolução de problemas** — pensar criticamente
- **Apresentação** — vender ideias e projetos

## 🎯 O que você vai conseguir fazer

- [ ] Comunicar ideias técnicas claramente
- [ ] Trabalhar em equipe de forma eficaz
- [ ] Liderar sem autoridade (influência)
- [ ] Apresentar projetos com confiança
- [ ] Gerenciar seu tempo e carreira
