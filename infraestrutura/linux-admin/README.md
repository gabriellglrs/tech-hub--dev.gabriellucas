# 🐧 Administração Linux

> Linux roda 90%+ dos servidores do mundo. Saber administrar Linux é essencial para segurança e infraestrutura.

---

## 📚 O que é Administração Linux?

**Administração Linux** é gerenciar servidores e sistemas Linux: configurar serviços, gerenciar usuários, monitorar recursos, automatizar tarefas e manter o sistema seguro e atualizado.

### Por que é importante?

- **90% dos servidores web** rodam Linux
- **Toda infraestrutura de segurança** roda em Linux
- **Hardening** — configurar Linux de forma segura
- **Scripts bash** — automatizar tarefas repetitivas
- **Logs** — investigar incidentes
