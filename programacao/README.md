# 💻 Programação (Python, Bash, Automação)

> Programação é a habilidade mais poderosa em tecnologia. Automatizar tarefas, criar ferramentas, resolver problemas.

---

## 📚 O que é esta área?

**Programação** inclui Python (automação, scripts, web), Bash (automação de terminal) e APIs (comunicação entre sistemas). Para segurança, programação é essencial.

### Por que é importante?

- **Automação** — scripts economizam horas
- **Exploits** — muitos são escritos em Python
- **Ferramentas** — Metasploit, Scapy são Python
- **Web** — APIs, backends, scraping
- **DevOps** — IaC, CI/CD, containers
