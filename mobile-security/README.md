# 📱 Mobile Security (Android/iOS)

> Smartphones são os dispositivos mais usados do mundo. Apps mobile armazenam dados sensíveis e são alvos constantes.

---

## 📚 O que é Mobile Security?

**Mobile Security** é proteger dispositivos móveis (Android, iOS) e aplicações mobile contra ameaças: engenharia reversa de APKs/IPAs, interceptação de tráfego, bypass de ssl pinning, e análise de código malicioso.

### Por que é importante?

- **Apps armazenam dados sensíveis** — bancários, saúde, localização
- **Engenharia reversa** — APKs podem ser descompilados
- **MITM em mobile** — interceptar tráfego de apps
- **Malware mobile** — cresce a cada ano
- **BYOD** — dispositivos pessoais no trabalho
