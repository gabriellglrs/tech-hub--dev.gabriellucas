# 🌐 Redes

> Redes são a fundação de tudo na tecnologia. TCP/IP, roteamento, firewalls, troubleshooting — sem redes, nada funciona.

---

## 📚 O que é esta área?

**Redes** estuda como dispositivos se comunicam: protocolos, roteamento, switches, firewalls, VPN e troubleshooting. Diferente do Módulo 0 (básico), aqui vamos ao avançado.

### Por que é importante?

- **Todo tráfego passa por redes** — entender é essencial
- **Firewalls** filtram por IP, porta e protocolo
- **VPNs** criam túneis seguros
- **Troubleshooting** — diagnosticar problemas de conectividade
- **Segmentação** — isolar redes para segurança
