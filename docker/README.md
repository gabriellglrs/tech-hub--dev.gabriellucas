# 🐳 Docker e Containers

> Containers isolam aplicações. São a base de DevOps, microserviços e cloud moderno. Segurança de containers é essencial.

---

## 📚 O que é Docker?

**Docker** empacota aplicações em **containers** — unidades leves, portáveis e isoladas. Diferente de VMs, containers compartilham o kernel do host e são muito mais rápidos.

### Por que é importante?

- **DevOps** — containers são a base
- **Cloud** — Kubernetes, ECS, Azure Container Instances
- **Segurança** — containers podem ter vulnerabilidades
- **Microserviços** — arquitetura moderna
- **CI/CD** — pipelines usam containers
