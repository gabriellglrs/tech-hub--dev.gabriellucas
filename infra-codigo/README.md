# 🔧 Infraestrutura como Código (IaC)

> Provisionar e gerenciar infraestrutura com código em vez de cliques. Reprodutível, versionável, auditável.

---

## 📚 O que é Infraestrutura como Código?

**IaC** é definir infraestrutura (servidores, redes, firewalls) em arquivos de código. Em vez de clicar em botsões no painel, você escreve código que cria tudo automaticamente.

### Por que é importante?

- **Reprodutibilidade** — criar o mesmo ambiente 100 vezes
- **Versionamento** — mudanças ficam registradas no Git
- **Auditoria** — saber quem mudou o quê e quando
- **Velocidade** — provisionar em minutos, não horas
- **Segurança** — compliance como código
