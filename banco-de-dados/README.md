# 💾 Banco de Dados (SQL, NoSQL, Administração)

> Dados são o ativo mais valioso de uma empresa. Proteger, administrar e entender bancos de dados é essencial.

---

## 📚 O que é esta área?

**Banco de Dados** inclui SQL (MySQL, PostgreSQL), NoSQL (MongoDB, Redis), administração (usuários, permissões, backup) e segurança (SQL Injection, hardening).

### Por que é importante?

- **SQL Injection** é a vulnerabilidade #1 do OWASP
- **Dados sensíveis** ficam em bancos de dados
- **Backup** — sem backup, dados se perdem
- **Performance** — queries lentas derrubam sistemas
- **Compliance** — regulamentações exigem proteção de dados
