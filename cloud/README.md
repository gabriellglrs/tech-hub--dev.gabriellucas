# ☁️ Cloud (AWS, Azure, GCP)

> Cloud é onde roda 90% dos sistemas modernos. Para segurança, você precisa entender como proteger ambientes cloud.

---

## 📚 O que é Cloud Computing?

**Cloud Computing** é usar servidores e serviços pela internet em vez de no seu computador local. Em vez de comprar um servidor físico, você aluga tempo em servidores da AWS, Azure ou Google Cloud.

### Por que é importante?

- **90% das empresas** usam cloud (AWS, Azure, GCP)
- **Segurança em cloud** é diferente de on-premise
- **Misconfiguration** é a causa #1 de violações em cloud
- **DevOps e DevSecOps** usam cloud como base
- **Vagas de segurança** pedem experiência em cloud
