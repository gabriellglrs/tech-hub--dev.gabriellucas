## 📚 O que é Threat Intelligence?

**Threat Intelligence (TI)** é coletar, analisar e usar informações sobre ameaças para tomar decisões de segurança mais inteligentes. Inclui OSINT, IOC, TTPs e threat hunting.

### Por que é importante?

- **Prevenir ataques** — saber o que vem
- **IOC** — indicadores de comprometimento
- **TTPs** — como atacantes agem (MITRE ATT&CK)
- **OSINT** — informações públicas valiosas
- **Resposta a incidentes** — contexto para investigação
