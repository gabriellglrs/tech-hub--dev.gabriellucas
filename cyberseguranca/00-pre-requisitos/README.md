# 📚 Módulo 0: Pré-Requisitos

> **Este é o ponto de partida.** Se você não sabe NADA sobre redes ou Linux, comece aqui. Estes são os fundamentos que TODO profissional de cybersegurança precisa saber.

---

## 🎯 Por que este módulo existe?

Antes de aprender a atacar ou defender, você precisa entender **como a internet funciona**. É como querer ser bombeiro sem saber o que é fogo — não funciona.

**Cada conceito aqui aparece DIRETO nos módulos de cybersegurança:**

| Conceito | Onde aparece depois |
|:---------|:---------------------|
| IP e Portas | Nmap (Módulo 1) |
| DNS | Reconhecimento, ataques DNS |
| HTTP | Web security, Burp Suite |
| Linux terminal | TODAS as ferramentas |
| TCP/IP | Análise de rede, Wireshark |
