**Passo 1 — Validar URLs com HTTP HEAD (per D-02):**

Para cada URL no lab-matrix.csv com status `pendente` ou `existente`, execute:
```bash
curl -sI -o /dev/null -w "%{http_code}" --max-time 10 "URL"
```

Resultados:
- `200` → marcar como `✅ Ativo`
- `301/302` → marcar como `⚠️ Redirect` (seguir redirect e verificar se cai em paywall)
- `404` ou timeout → marcar como `❌ Indisponível` + buscar alternativa (per D-06)
- Qualquer indicador de premium/subscribe na página → marcar como `⚠️ Premium`

Atualize o campo `status` no lab-matrix.csv com o resultado da validação.

**Passo 2 — Para salas indisponíveis (D-06):**
Se uma sala retornou 404 ou é premium:
1. Buscar equivalente na mesma plataforma (ex: sala renomeada)
2. Se não encontrar, buscar em outra plataforma
3. Registrar a alternativa no CSV com `status = "substituída"` e anotar a URL original
