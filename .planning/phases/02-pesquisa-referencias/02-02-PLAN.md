**Passo 1 — Validar URLs com HTTP HEAD (per D-02):**

Para cada URL nova no lab-matrix.csv (status `pendente`), execute:
```bash
curl -sI -o /dev/null -w "%{http_code}" --max-time 10 "URL"
```

Resultados:
- `200` → `✅ Ativo`
- `301/302` → `⚠️ Redirect` (seguir e verificar paywall)
- `404` ou timeout → `❌ Indisponível` + buscar alternativa (per D-06)
- Indicador de premium → `⚠️ Premium`

Atualize o campo `status` no CSV.

**Passo 2 — Para salas indisponíveis (D-06):**
