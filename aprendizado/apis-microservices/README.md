# 🔗 APIs e Microservices

> APIs são a espinha dorsal dos sistemas modernos. REST, GraphQL, gRPC — toda comunicação entre sistemas usa APIs.

---

## 📚 O que é esta área?

**APIs** são interfaces que permitem a comunicação entre sistemas. **Microservices** é uma arquitetura onde aplicações são divididas em serviços pequenos e independentes.

### Por que é importante?

- **90% dos sistemas** usam APIs REST ou GraphQL
- **Microservices** são a arquitetura padrão
- **Segurança** — APIs são alvos constantes de ataque
- **Integração** — conectar sistemas diferentes
- **Gateway** — gerenciar tráfego e autenticação
