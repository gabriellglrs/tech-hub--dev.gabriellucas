# Módulo 10: Governança e Criptografia

> Gerir segurança como negócio + proteger dados com criptografia.

---

## O que você vai aprender

- [ ] Rodar auditoria CIS com OpenSCAP e interpretar resultados
- [ ] Executar scan de hardening com Lynis e melhorar o score
- [ ] Calcular ALE/SLE/ARO para risk assessment
- [ ] Criar Information Security Policy mapeada para NIST CSF 2.0
- [ ] Criptografar/descriptografar com OpenSSL (AES-256, RSA)
- [ ] Usar GPG para criptografia de arquivos e assinatura digital
- [ ] Armazenar senhas com bcrypt (hash seguro)
- [ ] Gerar relatório de compliance automatizado (Lynis + OpenSCAP)

## Ferramentas

| Ferramenta | O que faz |
|:---|:---|
| OpenSCAP | Auditoria de compliance (CIS, PCI-DSS) |
| Lynis | Auditoria de hardening (score 0-100) |
| OpenSSL | Hashes, cifra, TLS, certificados |
| GPG | Criptografia de arquivos, assinatura |
| bcrypt | Hash seguro para senhas |
