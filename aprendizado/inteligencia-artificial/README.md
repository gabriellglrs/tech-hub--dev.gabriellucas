# 🤖 Inteligência Artificial e Machine Learning

> IA está em tudo em 2026. Entender como funciona é essencial para qualquer profissional de TI — não só para criar, mas para proteger e usar.

---

## 📚 O que é esta área?

**Inteligência Artificial** inclui Machine Learning, Deep Learning, NLP, Computer Vision e LLMs. Para DevOps/Segurança, o foco é: MLOps, AI Security, Prompt Engineering e uso de IA no dia a dia.

### Por que é importante?

- **MLOps** — deploy e monitoramento de modelos em produção
- **AI Security** — proteger sistemas de IA contra ataques
- **Prompt Engineering** — usar LLMs de forma eficaz
- **Automação** — IA automatiza tarefas repetitivas
- **Mercado** — IA é a habilidade mais requisitada em 2026
