# 📊 Dados (Analytics, Engenharia de Dados)

> "Dados são o novo petróleo." Toda empresa coleta dados, mas pouca gente sabe analisar. Essa é sua vantagem.

---

## 📚 O que é esta área?

**Dados** inclui Análise de Dados (SQL, Python, visualização), Engenharia de Dados (pipelines, ETL), Ciência de Dados (estatística, ML) e Gestão de Dados (bancos, quality).

### Por que é importante?

- **Toda empresa usa dados** — para tomar decisões
- **SQL** é a habilidade #1 em dados
- **Pipelines** — dados precisam fluir entre sistemas
- **Visualização** — contar histórias com gráficos
- **Compliance** — LGPD, GDPR protegem dados pessoais
