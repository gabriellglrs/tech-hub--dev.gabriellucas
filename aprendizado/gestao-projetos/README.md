# 📋 Gestão de Projetos (Agile, Scrum, ITIL)

> Todo profissional de TI precisa gerenciar projetos — mesmo que não seja PM. Agile e Scrum são padrão em 2026.

---

## 📚 O que é esta área?

**Gestão de Projetos** inclui metodologias ágeis (Scrum, Kanban), gestão de serviços (ITIL), e ferramentas (Jira, Asana). Não é só para gerentes — devs e ops precisam entender.

### Por que é importante?

- **Scrum/Kanban** — como 90% das equipes trabalham
- **ITIL** — padrão de gestão de serviços de TI
- **Jira** — ferramenta mais usada no mundo
- **Sprint Planning** — planejar trabalho em ciclos
- **Stakeholders** — comunicar valor para o negócio
