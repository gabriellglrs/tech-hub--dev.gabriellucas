# 🔄 Git Avançado

---

## 📚 O que é Git Avançado?

**Git Avançado** vai além do básico: branches strategies (GitFlow, Trunk-Based), rebase interativo, stash, bisect, cherry-pick, hooks e workflows de equipe.

### Por que é importante?

- **Equipes usam branches** — merge conflicts acontecem
- **CI/CD depende de Git** — pipelines inteligentes
- **Bisect** — encontrar commit que quebrou algo
- **Hooks** — automatizar ações antes de commit
- **Rebase** — manter histórico limpo
