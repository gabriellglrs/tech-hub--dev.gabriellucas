# 🏗️ Platform Engineering

> Construir plataformas internas que desenvolvedores usam self-service. Backstage, IDPs, golden paths.

---

## 📚 O que é Platform Engineering?

**Platform Engineering** é construir e manter uma plataforma interna que facilita o trabalho dos desenvolvedores: templates prontos, self-service, documentação automática. É DevOps no nível de organização.

### Por que é importante?

- **Developer Experience** — devs não precisam entender infra
- **Padronização** — todos usam as mesmas boas práticas
- **Velocidade** — criar projetos em minutos, não dias
- **Governança** — compliance automatizado
- **Escalabilidade** — suportar centenas de equipes
