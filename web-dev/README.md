# 🌐 Web Development (HTML, CSS, JS, APIs)

> Entender como a web funciona por dentro é essencial para web security. Você não pode proteger o que não entende.

---

## 📚 O que é Web Development?

**Web Development** é criar aplicações web: frontend (HTML, CSS, JavaScript), backend (Python, Node.js, PHP) e APIs (REST, GraphQL). Para segurança, você precisa entender como tudo funciona.

### Por que é importante?

- **90% dos ataques** são em aplicações web
- **SQL Injection, XSS, CSRF** — precisam entender HTML/JS
- **APIs** — a maioria dos sistemas modernos usa APIs
- **Burp Suite** — opera no nível HTTP/HTTPS
- **OWASP Top 10** — todos os vetores são web
