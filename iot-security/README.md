# 🌐 IoT Security (Dispositivos Embarcados)

> Internet das Coisas: câmeras, roteadores, smart home, industriais. Devices com firmware, sem patches, sempre vulneráveis.

---

## 📚 O que é IoT Security?

**IoT Security** é proteger dispositivos Internet das Coisas: câmeras, roteadores, smart home, dispositivos médicos, industriais (ICS/SCADA). Esses dispositivos são frequentemente vulneráveis por falta de atualizações.

### Por que é importante?

- **30+ bilhões de dispositivos IoT** no mundo
- **Mirai botnet** — IoT usou para DDoS massivo
- **Câmeras espionam** — vulnerabilidades expõem vidas
- **Indústrias** — ICS/SCADA afetam segurança nacional
- **Firmware** — pode conter backdoors e credenciais
